# Contributing to GrowTrust

Thanks for helping improve GrowTrust.

## Before you start
- Open an issue to discuss larger changes.
- Keep changes focused and explain the user problem they solve.
- Do not add bots, fake engagement, misleading growth claims, or deceptive seller practices.

## Development
1. Fork the repository.
2. Create a feature branch.
3. Make and test your changes in a modern browser.
4. Check mobile layouts and keyboard accessibility.
5. Open a pull request with a clear summary and testing notes.

## Pull request checklist
- [ ] The change works on desktop and mobile.
- [ ] Forms have labels and useful validation.
- [ ] No secrets, credentials, or personal customer data are committed.
- [ ] Claims about results, retention, or guarantees are accurate.
- [ ] Demo-only behavior is clearly identified.
