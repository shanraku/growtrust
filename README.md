# GrowTrust
### Real Growth. Transparent Results. Trusted Services.

GrowTrust is an open-source prototype for a transparent marketplace focused on compliant social media growth and digital marketing services.

**Built in public by SUNRAKU** · [GitHub](https://github.com/shanraku)

## What we're building
- A marketplace for content strategy, creator discovery, profile optimization, and other legitimate marketing services.
- Customer dashboard preview with sample order milestones and support flow.
- Seller dashboard preview to draft service listings locally.
- Clear package scopes, deliverables, timelines, and exclusions.
- Order milestones and evidence-based progress updates.
- Retention reporting where meaningful metrics are available.
- Seller reviews, complaints, and a fair dispute-resolution process.
- Customer and seller dashboards, with privacy and security built in.

## Trust principles
- No bots, fake followers, fake views, or artificial engagement.
- No claims of guaranteed or permanent follower counts, views, reach, or sales.
- Customers should see exactly what a package includes before ordering.
- Any refund or replacement policy must be explicit, measurable, and fair.
- Real payments and live orders will not be enabled until the backend, security, seller verification, and dispute workflows are ready.

## Current status
This repository currently contains a **frontend prototype**. Service prices and timelines shown in the UI are illustrative only. Demo requests are stored locally in the visitor's browser. No payment is collected, no real order is created, and no service delivery is promised.

## Run locally
Open `index.html` in a modern browser, or serve the folder with any static HTTP server.

## Planned roadmap
1. Accessible marketplace UI and service detail pages.
2. Authentication and role-based customer/seller dashboards.
3. Verified seller onboarding and service moderation.
4. Secure order lifecycle, milestone evidence, and audit trail.
5. Retention measurement, complaint handling, and policy-based refunds.
6. Security review, privacy review, tests, and deployment.
